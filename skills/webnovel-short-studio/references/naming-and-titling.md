# 短篇人物命名与商业/质感标题规范（去 AI 味准则）

在 `hook`、`beat`、`draft`、`check` 与 `export` 阶段按需读取。核心思路：**小名单防堆砌 + 套路熔断 + 商业/质感双轨书名 + 章节反剧透**，消除“全员沈顾陆墨砚”和“剧透式章名”，同时释放商业信息流书名的点击率。

---

## 上篇：人物命名（适配 2–5 人短篇小名单）

1. **禁止“低频文艺姓 + 高频意象字”双套路叠加**：避开低频文艺姓（沈、顾、陆、裴、谢、傅、晏、萧、祁、岑、郁、温）叠加下述意象字（如沈清晏、顾见微、谢惊寒）。允许“常见大姓 + 雅致名”（张清晏）或“文艺姓 + 朴素名”（沈涛）。
   - **24 字高频意象限流池**（2–5 人短篇全篇至多出现 1 字，古风武侠至多 2 字）：**清、晏、舟、川、微、晚、辞、烬、寒、墨、渊、衡、溯、栖、疏、尘、妄、诀、凛、昭、昀、屿、汐、言**。
2. **短篇小名单实用配额（取代心算百分比）**：
   - **现代 / 现实 / 悬疑 / 科幻**：主力用常见大姓与常规姓（王、李、张、刘、陈、杨、黄、赵、周、吴、徐、孙、马、林、高、宋、许、程、梁、方等），**低频文艺姓至多 0–1 人**；科幻把概念感留给代号/工号，户籍名保持简明。
   - **武侠 / 仙侠 / 东方奇幻**：大姓与江湖姓混搭，罕见复姓（南宫/慕容/司徒等）全篇至多 0–1 族，区分本名、道号与绰号。
   - **其他题材速查**：民国/年代文贴地域大姓与时代实用名（禁古偶风）；古代朝堂按阶层分层（士族重字辈避讳，平民用大姓+排行/粗名，禁丫鬟驿卒配雅名）；西幻避开高频译制套名（艾莉丝/艾莉娅/亚瑟/莱昂/凯尔/卢修斯/维克多等）并统一区域音系。
3. **父母/时代视角反剧透**：姓名反映出生年代与家庭阶层，禁标签剧透起名（冷酷必带寒、复仇必带烬、科技必带序）。
4. **龙套降噪与同屏区分**：路人、保安、邻居一律大姓或社会称呼（老陈、王师傅、张婶、刘二）；高频同框角色（非同族）避免同姓、尾字同音或字形相近。

## 下篇：作品书名与章节命名

### 一、五大书名型谱（商业与质感分轨）

区分「内部一句话梗概」与「正式书名」；**知乎盐言/悬疑质感向优先型 1–4，番茄/七猫/点众/黑岩信息流分发完全支持高点击型 4 与型 5**：

| 命名型谱 | 建议长度 | 适配平台与气质 | 范式参考 |
|---|---|---|---|
| **1. 意象 / 器物 / 地标短名** | 2–5 字 | 克制耐看｜知乎盐言、高质感情感/悬疑 | 《金缮》《借衣》《谎言额度》 |
| **2. 概念 / 反差短语** | 4–8 字 | 点破规则错位或关系张力｜全平台通用 | 《借来的嫁衣》《替身不上班》《旧瓷新主》 |
| **3. 人物 / 关系锚点** | 3–7 字 | 落脚职业、身份或微妙关系｜知乎盐言 / 悬疑 | 《补瓷人》《阁楼房客》 |
| **4. 半句对白 / 悬念截断** | 6–12 字 | 刺痛感与画面钩子兼备、不剧透｜**全平台高转化主力** | 《这碗瓷，我不补了》《退婚那天下了场雨》 |
| **5. 信息流直述强钩子** | 10–18 字 | 痛点/奇观/反差直给｜**番茄/七猫/点众/黑岩主推**（七猫 ≤18 字，建议 ≤17 字留余量） | 用具象生活细节、反常识规则、动作或反问切口 |

**书名熔断铁律 & 异构 3 备选原则**：
- **只熔断陈旧复刻模板，不打压商业钩子**：型 5 避开机械照抄的 `被……后，全家/前任悔疯了`、`离婚后，我转身……` 疲劳复句，换新鲜奇观或锋利对白。
- **异构 3 备选**：给备选书名时须跨型谱输出 3 个不同气质方案（如：`型 1/2 精炼短名` + `型 4 半句悬念` + `型 5 商业强钩子`），禁连给 3 个换词不换骨的雷同长句。

### 二、章节名四体制与四项熔断（书名与章名职责分离）

哪怕书名选了直给高点击长标题，**正文章节名仍须简短留白不剧透**。开篇前锁定 1 套：
- **体制 A｜极简词眼（2–4 字，短篇强推）**：抓核心物件/时间/动作（如 `01 凉汤`、`04 漆盒`）。
- **体制 B｜单元母题 + 序号**：适配 `microdrama` 单元结构（如 `婚纱（一）`、`婚纱（二）`）。
- **体制 C｜轻短语切片（4–8 字）**：一句短台词或异常切口，点到即止（如 `多出一寸的袖口`）。
- **体制 D｜纯序号无副标题（`一` / `01` / `第一章`）**：`flash` 超短篇一等选项，适合知乎盐言一气呵成读完。

**四项熔断**：① 禁剧透反杀结果；② `A与B` / `XX的YY` 占比 ≤20% 且相邻不连撞；③ 禁万能空壳词（`暗流涌动`、`风暴前夕`、`真相浮出水面`、`命运的转折`、`尘埃落定`）；④ 导出前竖扫全部章名核对节奏与序号连贯。
