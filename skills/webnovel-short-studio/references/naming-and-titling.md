# 人物命名平衡与作品标题/章节命名规范（去 AI 味准则）

在 `hook`（立项与人物设计）、`beat`（节拍与章节体制锁定）、`draft`（正文临场配角与章名）及 `check / export`（审校与定稿起名）阶段读取。核心治理思路是**用“型谱配额 + 套路熔断 + 按题材/平台分支适配 + 输出前静默自检”打破 AI 命名惯性**，不搞一刀切封杀，但坚决消除“全员沈顾陆墨砚”和“满屏超长直述剧透标题”。

---

## 上篇：人物命名平衡与去 AI 味规范

### 一、通用底层规则（所有题材强制生效）

1. **比例配额取代一刀切**
   - 严禁全面封杀某一类姓氏，也严禁让单一风格垄断名单。所有出场人物按作品整体或单次生成批次构成合理的社会样本分布，具体比例遵循下文对应题材分支。
2. **组合熔断机制（反 AI 味核心）**
   - 限制高频 AI 意象单字的密度：在现代、历史、科幻题材中，每 10 名角色里来自下述“高频意象限流字池”的字累计出现不超过 1–2 次；武侠仙侠题材不超过 3 次。
   - **禁止双重套路叠加**：严禁“低频文艺姓 + 高频意象字”的组合。允许“文艺姓 + 朴素名”（如沈涛、顾德明），也允许“常见大姓 + 雅致名”（如张清晏、李知衡），但回避“沈清晏、顾见微、陆星移、谢惊寒”这类双重高频拼装。
   - **中文高频意象限流字池（限流而非封杀）**：清、晏、舟、川、微、晚、辞、烬、寒、墨、渊、衡、溯、栖、疏、尘、妄、诀、凛、昭、昀、屿、汐、言。
3. **父母/时代视角与反剧透原则**
   - 姓名只反映角色出生时的年代、地域、阶层、宗族习惯与父母文化水平，而非作者用来剧透角色后天性格、职业或命运的标签。
   - 禁止“功能贴标签式起名”（如冷酷必带寒/沉、复仇必带烬、搞科技必带序/原、反派必带阴鸷字眼），鼓励姓名气质与角色性格存在自然反差。
4. **戏份分层与龙套降噪**
   - 把命名辨识度预算留给主角与核心配角；功能性龙套、路人与基层服务人员优先使用常见大姓，或直接采用符合时代语境的社会称呼（如老陈、王师傅、刘二、赵婆子），严禁给龙套强行配文艺全名。
5. **同屏防撞与听觉差异**
   - 同一阵营、家庭或高频同框的角色，除明确设定为同族排字外，避免同姓扎堆、尾字同音、平仄声调结构雷同或字形过于接近，确保读者能靠字面轮廓瞬间区分。

### 二、分题材特化参数（按当前作品题材自动匹配）

#### 分支 A：现代都市 / 现实悬疑 / 职场商战
- **姓氏配额**：
  - 60%–70% 高频常见姓（王、李、张、刘、陈、杨、黄、赵、周、吴、徐、孙、马、朱、胡、郭、何、罗、高、林等）；
  - 20%–30% 中频常规姓（郑、梁、宋、唐、许、邓、冯、韩、曹、曾、彭、程、袁、田、吕、丁、任、姚、方、蔡等）；
  - 不超过 10% 低频或自带文艺滤镜姓氏（沈、顾、陆、裴、谢、傅、晏、萧、祁、岑、郁、温等），仅在角色家世、地域特征或核心记忆点需要时启用。
- **命名逻辑**：
  - 严格锚定角色出生年代与家庭背景（如 60/70 后偏务实与时代印记，80 后偏双字简明或单字，90/00 后偏多元与轻书卷气，同时区分城市知识分子家庭与县城/乡镇家庭的取名差异）。
  - 职场或圈层需要时，区分“身份证本名”与“英文名/花名/绰号”，不要把网名审美直接写成户籍名。

#### 分支 B：民国 / 近代 / 年代文
- **姓氏配额**：
  - 遵循当地宗族与地域聚居特征（如江南、华北、岭南、东北的高频姓氏差异），大姓与地域常见姓合计占 80% 以上；地方望族可使用对应历史大姓，但避免现代言情高频姓泛滥。
- **命名逻辑**：
  - **民国时期**：体现新旧交替的阶层分化——旧式世家重字辈与表字，新派知识分子家庭可见西学、救亡或现代意象，商贾与底层百姓偏实用、祈福或直接以排行、乳名行世；严禁把现代古偶或晋江网文审美套进民国角色。
  - **建国后至改开年代**：体现兄妹排字、时代热词、实用寓意及“小名/大名分离”，同时避免全员脸谱化成“建国、翠花、铁柱”，保留地域文化与家庭审美梯度。

#### 分支 C：古代历史 / 架空权谋 / 世家朝堂
- **阶层分层配额（核心原则：按阶层而非均匀分配）**：
  - **皇室、门阀与高门士族**：可合理提高中古及传统望族姓氏权重（如崔、卢、郑、王、李、韦、杜、裴、谢、萧、柳、顾、陆、袁、范、薛等），但必须严格遵守**宗族字辈、避讳礼法、名与字语义呼应**的传统规则，严禁写成现代古偶风辞藻堆砌。
  - **寒门士子、中小地主与普通官吏**：以常见大姓及中频姓为主（王、李、张、刘、陈、周、吴、赵、孙、胡、郭、徐、马、朱、何、杨、韩、曹、高、冯等），名字偏向儒家伦理、经史典故与务实期许（如安、宁、正、明、承、远、景、谦、敬、怀、延、仲等）。
  - **平民、兵卒、匠户与仆役**：85% 以上使用大姓 + 排行/小名/朴素粗名（如赵大郎、刘福安、王二柱、陈阿四、张五、孙婆子），严禁让驿卒、丫鬟、铁匠使用风花雪月的三字雅名。
- **古代女性命名规范**：
  - 官宦世家女性注重闺名、行第（如崔七娘、裴三娘）与“夫姓+本姓氏”的正式称谓；民间女性以朴素闺名、排行或某氏为主，避免全员“映雪、清婉、未央”。
- **称谓纪律**：
  - 严格区分**名、字、号、排行、爵位/官称**的使用场景（平辈雅称用字，长辈/君主直呼其名，同僚多称官职或籍贯）。

#### 分支 D：古风武侠 / 仙侠志怪 / 东方奇幻
- **姓氏配额**：
  - 40%–50% 常见大姓（保留江湖烟火气与经典厚重感，如张、李、王、杨、郭、周、陈、黄、林、徐、孙、马等）；
  - 30%–40% 中频及传统江湖质感姓氏（萧、楚、傅、沈、谢、燕、霍、苏、温、唐、叶、白、程、方、段、戚等）；
  - 不超过 15% 生僻姓或复姓（南宫、慕容、司徒、公孙、上官、独孤、东方等复姓严格限流，单卷或整书原则上不超过 1–2 族，且必须绑定特定宗门、血脉或地域设定）。
- **命名逻辑**：
  - 明确区分**俗家本名**、**道号/法号**（如清虚、玄真、无崖、妙音）与**江湖绰号**，不把道号或招式审美直接当成普通凡人的出生本名。
  - 避免全员扎堆“寒、墨、渊、烬、夜、影、离、殇、凌霄、无极”，多从具体器物、山川草木、节气天文、古朴金石与利落武人节奏中取材。

#### 分支 E：近未来 / 赛博 / 硬科幻 / 制度科幻
- **姓氏配额**：
  - 维持现实人口基数：常见大姓仍占 60%–70%，中频姓占 20%–30%，低频姓不超过 10%。严禁因为“科幻感”就把全员姓氏换成纪、商、卫、秦、陆、祁。若涉及跨国或多族裔背景，按地区真实人口分布自然混编。
- **命名逻辑**：
  - 户籍本名顺延未来一至两代人的命名演进，偏向简明、中性化、低修饰感（适度提高清爽双字名比例），避免“溯、原、序、零、彻、星河、纪元”过密堆积。
  - 区分**法定本名**与**工号、系统 ID、网络呼号、行动代号**——把冷峻感或概念感留给代号，把真实感留给本名。

#### 分支 F：西幻 / 异世界 / 译制腔奇幻
- **防译制 AI 味规则**：
  - 严禁高频 AI 西幻名字扎堆（如艾莉丝、艾莉娅、莉莉丝、亚瑟、莱昂、凯尔、卢修斯、塞巴斯蒂安、维克多、奥利维亚、伊芙琳、索菲亚、克莱尔等，整批角色中出现不超过 10%）。
- **语言学一致性**：
  - 按世界观内的不同国家/民族/地区固定音系（如日耳曼/北欧硬朗音节、拉丁/罗曼流利音节、斯拉夫辅音群或自定义构词法），同一地区的人物姓名必须听感统一。
  - 区分贵族完整名号（名 + 领地/家族姓）与平民单名/职业姓（如铁匠、磨坊主、地名来源），避免农夫和公爵听起来像同一个家族。

### 三、人物命名输出前静默自检清单

短篇核心人物仅 2–5 人，**越是小体量名单越容易全员踩进“沈顾陆 + 墨砚晚清”陷阱**。定稿人物表前必须内部核验：
1. 统计当前批次姓氏分布，是否符合所选题材分支的比例配额？（现代短篇 3–5 名核心角色里，最多只允许 0–1 个低频文艺姓！）
2. 是否存在“低频文艺姓 + 高频意象字”的双重套路组合？如有，拆解替换其中一端。
3. 龙套与底层角色是否被无意赋予了过度精致的姓名？如有，立即降噪。
4. 同一阵营或高频同框角色是否存在首字同姓、尾字同音或读音拗口的问题？
5. 每个名字是否经得起追问：“这个角色的父母在那个时代、那个阶层，真的会给他起这个名字吗？”

## 下篇：作品标题与章节命名规范（去超长直述腔与反剧透）

### 一、核心原则

1. **型谱多元取代单一惯性**：不封杀信息流直述型书名，但彻底戒除“每篇短篇都只会起 15 字逗号直述长句”的单一惯性。
2. **书名与章节名职责分离**：即便某篇番茄/七猫短篇为了点击率把**书名**定为直述强钩子，正文里的**章节名也必须保持简短、留白、不剧透**，绝不把每章写成微缩版剧情总结。
3. **梗概不冒充标题**：明确区分「一句话高概念（内部说明）」与「正式书名」，避免直接把选题梗概拿来做书名。

### 二、作品总标题五大命名型谱

| 命名型谱 | 建议长度 | 构词方式与气质 | 典型范式 |
|---|---|---|---|
| **1. 意象/器物/地标短名** | 2–5 字 | 抓承载核心情感或脑洞隐喻的具象物件/手艺/地点 | 《金缮》《借衣》《碎瓷》《谎言额度》 |
| **2. 概念/反差短语** | 4–8 字 | 动宾/偏正短语点出核心规则错位或关系张力，不写长句 | 《借来的嫁衣》《替身不上班》《坏账清算》《旧瓷新主》 |
| **3. 人物/关系锚点** | 3–7 字 | 落脚在职业、身份或微妙关系位置 | 《补瓷人》《未婚夫的青梅》《阁楼房客》 |
| **4. 半句对白/悬念截断** | 6–12 字 | 截取最锋利的一句情绪台词或半截事态，有刺痛感但**不剧透结局** | 《那件绣着我名字的嫁衣》《这碗瓷，我不补了》《退婚那天下了场雨》 |
| **5. 直述事件/算法强钩子** | 10–18 字 | 面向番茄/七猫/点众/黑岩信息流点击（**按平台按需选用，不作唯一默认**） | 优先用具象细节/动作/反问切口 |

**书名熔断铁律**：
- 限流单一复句模板：即使用型 5，也严控 `……后，我转身……`、`被……后，全家/前任悔疯了`、`离婚/退婚后，我……` 等千篇一律逗号两截式。
- **异构 3 备选机制**：凡在 `hook` 或 `export` 阶段提供备选标题，必须跨型谱输出 3 个气质不同的方案（如：`意象/概念短名` + `半句对白/情绪悬念` + `按需附 1 个信息流直述备选`），严禁 3 个全是换词不换骨的长直述句。

### 三、章节名四套可选体制与熔断清单

在 `00_脑洞与节拍.md` 中先锁定 **1 套统一体制**：
- **体制 A｜极简词眼 / 名物体制（2–4 字，短篇强推荐）**：取本章最具刺痛感或张力的物件、数字、时间或动作（如 `01 热栗子`、`02 凉汤`、`04 漆盒`、`07 温水`）。
- **体制 B｜单元母题 + 序号体制**：适合 2–5 万字 `microdrama` 或悬疑单元结构，每 3–5 章共享一个单元名（如 `婚纱（一）`、`婚纱（二）`）。
- **体制 C｜轻短语 / 半句切片体制（4–8 字）**：抓一句短台词、小异常或当场对峙切口，**点到即止不揭底**（如 `多出一寸的袖口`、`别碰那只盒`、`不够体面`）。
- **体制 D｜纯序号 / 无副标题体制（`一` / `01` / `第一章`）**：**超短篇（`flash`）一等选项**——适合知乎盐言、番茄情感/悬疑短故事一气呵成读完，避免硬憋副标题打断沉浸感。

**章节名四项去 AI 味熔断清单**：
1. **禁剧透总结体**：禁止把本章反杀、揭穿或打脸结果直接写进章名（如 `温水揭穿造假真相，全场震惊`）。
2. **限流「`A与B` / `XX的YY`」连排机械体**：全篇章节名里 `……与……`、`……的……` 占比**不超过 20%**，严禁相邻两章撞句式。
3. **限流万能空泛词**：禁用放任何小说都成立的空壳章名（如 `暗流涌动`、`风暴前夕`、`真相浮出水面`、`命运的转折`、`破晓时分`、`尘埃落定`）。
4. **目录竖扫静默自检**：完稿导出前竖扫全部章名，确认不撞句式、不剧透反转、长短顺眼。

## 本套件专属默认档位（`webnovel-short-studio`）

- **知乎盐言 / 女频强情绪 / 悬疑高质感短篇**：书名优先 **型 1（2–5 字）**、**型 2（4–8 字）** 或 **型 4（6–12 字半句悬念）**；章节优先 **体制 D（纯序号）** 或 **体制 A（2–4 字词眼）**。
- **番茄短故事 / 七猫 / 点众 / 黑岩**：书名可在 **型 2 / 型 4 / 型 5** 中按需选定（给备选时仍须提供异构 3 风格）；章节名一律采用 **体制 A / 体制 C / 体制 D**，严禁跟随书名一起写成长句剧透。
