# 平台建书与投稿填表词库（七猫短故事 & 番茄小说）

在 `export`（汇总交付 / 准备投稿发布）阶段，当目标平台为 `qimao` 或 `fanqie`（或用户明确要求生成投稿建书信息）时读取。根据 `00_脑洞与节拍.md`、正文成稿、目标平台与受众视角，自动生成可直接照抄勾选的**《投稿建书填表清单》**（可同步保存为 `<交付目录>/{书名}_投稿建书清单.md`）。

---

## 一、选标防雷铁律（输出前必检）

1. **严格原词挑选，严禁自造标签**
   - 所有推荐分类与标签**必须 100% 逐字取自下文对应平台的预设原词库**，绝不允许模型凭记忆或跨平台混搭自造词。
   - 跨平台同义词必须按目标平台词库映射：例如**七猫词库中没有`追夫火葬场`**，写男频追夫/反杀投七猫时，应从七猫情节词库中改选`后悔流`、`打脸虐渣`、`全家火葬场`、`离婚后`、`复仇`、`逆袭`等真实存在的原词；而在番茄小说则可直接选用`追夫火葬场`、`打脸逆袭`。
2. **频道与受众视角严格隔离（防推流错配）**
   - **男频视角作品**：严禁投进女频分类，也严禁勾选`现代言情`、`古代言情`、`幻想言情`、`衍生言情`、`古言虐恋`、`古言甜宠`、`古风世情`、`现言甜宠`、`大女主`、`女性成长`等女频定向标签。
   - **女频视角作品**：切勿误投男频专属主分类（如番茄的`男生生活`、`男生情感`、`男频脑洞`、`男频衍生`）或男频向标签（如`多女主`、`无女主`、`护花高手`、`兵王`）。
3. **结局走向与情绪基调防货不对板（防差评弃读）**
   - **绝不回头 / 彻底切割 / 换娶 / 换嫁文**：严禁勾选`破镜重圆`、`先虐后甜`、`甜宠`、`双向奔赴`（若另牵新官配有真实甜度，需在避坑说明里点清并谨慎评估是否勾选`甜宠`，严禁给前任线打`破镜重圆`）。
   - **男频追夫 / 憋屈反杀文**：慎选`虐文`（容易劝退男频爽点受众），情绪标签优先选`爽文`。
   - **虐恋 / BE / 开放式结局**：切勿错勾`HE`或`甜宠`引发读者落差。
4. **表单硬规格复核**
   - 七猫建书：`作品名称` 须 **≤ 18 字（建议 ≤ 17 字留安全余量，含标点与字母，输出清单标明实测字数）**，`作品简介` **建议 120–300 字，平台上限 ≤ 500 字**，`作品标签` **4 组每组必选 1–3 个**。
   - 番茄建书：按 5 组原词库精准匹配，勾选数量遵循各栏位引导，突出最核心的主分类与 1–2 个强转化情节/情绪词。

- **内容声明**：{如：原创首发，无抄袭洗稿}
