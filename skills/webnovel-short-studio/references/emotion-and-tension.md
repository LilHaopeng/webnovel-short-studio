# 感染力文笔、人物立体化与活人感创作指南

在 `hook`（立项压测）、`voice`（原声定调）、`draft`（正文撰写）与 `check`（B 轨编辑审稿）阶段读取。

> **赛道适用边界**：本指南主攻**强情绪、关系博弈与都市/古言/现实/复仇爽文主盘**，专治“情绪太平、公文说明书腔、纸片工具人、前大半篇纯隐忍取证”。若你在写**规则怪谈、冷面沙雕喜剧或硬核科幻脑洞**，请只吸收其中的「反派现实逻辑、配角立体度、去公文说明书腔与生活体感」，**切勿强行塞入苦情痛觉或家庭狗血戏**，保持本赛道应有的冷峻或荒诞调性。

---

## 一、 情绪感染力四法（治“文笔太平 / 缺乏代入感”）

### 1. 用具象微感官与温度差替代抽象情绪空壳
读者对“心如刀割、胃里翻江倒海、眼底最后一丝温度熄灭、骨节/指节发白、指甲嵌进掌心”早已免疫。让文字扎进人心的核心原理，是**用「具象物件 + 感官温度差 + 反常小动作」承载情绪，把抽象词留给读者自己脑补**：
- **核心写法**：不要写“他感到极度屈辱和心寒”，改写**现场最扎眼的日常细节**（物件的冷热/磨损/错位、味觉发苦发涩、声音突然停顿、一个刻意维持体面的多余小动作）。
- **关于“冷笑”的口径澄清**：“冷笑”本身是正常高频词，不封杀；真正拖垮质感的是**空洞单句走过场**（如“他冷笑一声，决定不再手软”），如果写冷笑，须配具体动作、物件落点或一针见血的潜台词，而非拿它当情绪句号。
- **严防跨书复制固定道具**：不要在每篇小说里重复抄写同一套道具意象，每次必须从**本篇角色的职业、居住环境和当下场景**现场长出专属物象。

### 2. 强情绪赛道先留“痛觉”，再写“清醒与反杀”
- “内核稳、不内耗”绝不等于“没有痛觉神经”。如果主角撞破背叛 30 秒就丝滑进入“备份数据、发律师函、走流程”的无痛模式，读者来不及心疼主角，后面反杀的爽感势能直接腰斩。
- **情绪落差结构**：先给 **1–2 个扎进肉里的真痛瞬间**（哪怕只有两三句：回想起自己曾经的认真、口袋里白准备的东西、一句轻飘飘的嫌弃），让读者胸口真沉下去，再写主角咽下血气、冷静反击。

### 3. 戒除“公文 / 法务办件说明书腔”
短篇爽文不是法治通稿，也不是政务办事流程图：
- **口语化简称文件**：动辄 12–25 字的正式公文书名号（《关于……单方撤销/免责声明》之类）密集出现会瞬间吸干情绪，文中改用自然口语简称（“那份免责单”“退股书”“撤销函”）。
- **压缩程序步骤，放大当面撕裂**：把“备案 → 回执 → 核验 → 传唤 → 裁定”压成一句结果交代，把笔墨全砸在**谎言当场碎裂的表情、嘴硬、互相甩锅、体面剥落与当面交锋**上。

### 4. 用市井烟火气与精准反讽造“活人语感”
从头绷到尾、每句放狠话极易显得做作。恰当嵌入贴合身份的烟火白描或克制冷讽（写人物嘴上标榜体面、手上却算盘打得精响的反差细节），寥寥两笔就能让画面长出血肉、让主角瞬间讨喜。

## 二、 人物立体化与关系张力（融合番茄官方人物深化法）

### 1. 主角表里反差 + 角色生活体感
- **表里反差切面**：别贴单一标签（“冷静复仇者”）。给主角设一对鲜活反差（体面/懒散/嘴毒外壳 × 护短/洁癖/隐秘旧伤），并让主角的每次重要选择**付出真实成本**（拒绝毫无代价地两边好处全占）。
- **角色生活体感（让人物长在真实重力里）**：适时带出三类具体身体信号——① **吃穿起居习惯**（偏爱的便宜吃食、常穿的旧衣磨损）、② **疲惫与疼痛**（熬夜后的太阳穴发胀、久站发酸的膝盖、咽炎发紧）、③ **压力下的微小身体习惯**（焦虑时转瓶盖、强装镇定时把袖口卷齐）。

### 2. 反派立体化四原则（彻底根除卡通降智自爆）
严禁让反派为了方便主角抓把柄而做反常识蠢事（如对着镜头大声招供、把犯罪底稿摊桌面等人拍）。按**四原则**立住真实可恨的对手：
1. **道德支点**：反派在自己的价值体系里觉得自己“没错”或“是被逼的”（如认为占亲人便宜是理所应当的补偿，或觉得阶层本就弱肉强食）。
2. **沉没成本（停不下来的理由）**：为什么不能收手？因为退一步就会失去已经攥在手里的面子、资产、地位或秘密，只能一路加码赌下去。
3. **局部正确性**：反派的某句话或某个判断，从现实某个角度看确实戳中痛点或带着几分残酷真相——这会让主角的反击更有分量。
4. **致命盲区**：反派的翻车必须源于真实人欲弱点——**轻视**（笃定主角好拿捏不敢翻脸）、**虚荣**（在亲友/圈层面前下不来台硬撑）、**双标**与**信息错位**。越像现实里真会遇到的恶心人，读者的血压和代入感越高。

### 3. 反工具人配角四招 + 非主角隐秘联系
官配、盟友与关键配角绝不能是“空降签字兜底的外挂”，落地时至少命中以下 2–3 招：
1. **主角不在场时自行推进自身事务**：配角有自己的日程、麻烦和行动线，不是在原地等主角召唤的 NPC。
2. **帮主角必须付出真实代价**：出手搭把手会担风险、损人情或触碰底线，因此这份偏爱或结盟才值钱。
3. **拥有主线之外的独立人生与算盘**：自带脾气、防备心、嗜好或利益诉求，与主角先试探、互怼、交换筹码再建立信任。
4. **关键时刻拒绝配合主角一次**：基于自身立场、顾忌或原则，在某个节点明确说“不”，逼出新的关系张力或博弈弧线。
- **加分项——配角间不经主角的独立隐秘联系**：哪怕短篇只有 4–5 人，给两位配角之间留一条不通过主角的旧识、欠债、互相防备或利益勾连，群像瞬间活起来。

### 4. 对话写潜台词与机锋推拉（删“信息播报台词”）
- 信息播报式台词（把调查报告当台词整段念出来）最毁灵气。关键对手戏里，说话人应嘴上捧着、逗着、试探着，句句戳在对方最虚的那根神经上；感情线通过互怼、口是心非与微妙小动作暗涌张力。
- **检验铁律**：遮住说话人名字，光看台词能分出谁是谁吗？每轮对话除了传信息，是否把两人关系往前或往裂痕深处拱了半寸？

## 三、 脉冲式节奏与强情绪审美对齐

1. **严禁前 60% 全在隐忍取证、废除纯筹备过场章**：绝不允许整章只干“对账、公证、装设备、等明天”。必要信息核对压成三两句，直接融进当下正面冲突或关系推拉里。
2. **每章必带“现场微戏眼”**：终极大底牌留在中后段，但每章内部都须落地至少 1 个当场见效的抓手——刺穿小谎言、拿回局部体面、让对手心里犯嘀咕，或让情感天平肉眼可见地倾斜一次。
3. **强情绪主盘审美对齐**：先立“情”，再谈“局”（阴谋反杀是服务情绪爆发的燃料，不反客为主）；情绪弧线须**有峰有谷**——压抑处藏一句轻快冷讽或微小暖意，甜处藏一根细刺，虐处留一口骨气，有呼吸、有温度差才叫感染力。
