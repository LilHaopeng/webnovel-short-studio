# 手机端网感媒介校准与单篇声口定调

在 `voice`（开篇试写定调）与 `draft`（正式撰写/续写）阶段读取。

> **核心纪律**：本指南提供的是**媒介校准**（避免滑回传统出版长段说教腔），不是**桥段演出说明书**。绝不为所有作品套用同一种口吻、同一种打脸流程或刻板的逐段字数硬红线。

---

## 1. 先选本篇「推进叙事类型」（告别一刀切）

不同网文品类的网感来源不同，先在 `00_脑洞与节拍.md` 中选定主形态，后续正文与 `lint_webnovel.py` 均据此对齐：

| 推进类型 (`--narrative`) | 适用题材 | 核心推进引擎 | 对话与叙述体感 |
|---|---|---|---|
| **`dialogue`（强对话交锋型）** | 微短剧爽文、都市/古言职场家庭赌局、群像博弈打脸 | **短促台词一来一回 + 当下动作反应** | 对话占主体；信息尽量拆进质问、顶嘴、甩证据、补刀的交锋里，几乎不写大段旁白解释。 |
| **`first_person`（第一人称强叙述吐槽型）** | 知乎盐选、番茄第一人称复仇/发疯/重生/高概念自述 | **极强主观口吻 + 犀利短评 + 密集剧情翻转** | 不硬凑水对话；靠主角贴脸讲故事的狠劲、荒诞感、毒舌吐槽和关键节点的一锤定音台词拉爽感。 |
| **`rules`（规则/悬疑信息流型）** | 规则怪谈、系统漏洞推演、无限流脑洞、高智商反转 | **冷峻观察 + 反常细节 + 规则条目与信息差翻转** | 允许穿插规则清单或冷静推演段，用“规则/冷静长段 + 一句发凉的短句破绽”打出强反差。 |

---

## 2. 手机竖屏媒介校准（防滑回出版长段腔）

手机屏幕一行约 16–20 个汉字，一屏只能容纳约 15–18 行。写作时记住四条高维体感即可，**边写边数具体字数反而会写僵**：

1. **以 1–3 行短段为主基调，但保留长短反差**
   - 常规叙述与动作交代轻快利落，一段说清一个动作或一层意思就换段；情绪爆点、狠话、反转揭晓、刺眼细节自然单句成段。
   - **主动保护长短反差**：遇到需要一口气甩出去的毒舌连珠炮、压抑蓄势、规则清单或关键揭秘时，可以放心写出 90–140 字的完整强段，再用一句 5–10 字短句收口——**严禁把整章强行切碎成满屏 20–30 字的均匀“AI 电报排骨”**。
2. **拆碎百字演讲台词**
   - 网文最出戏的出版病之一，是角色一口气说 120 字逻辑严密的完整论述（像开评审会汇报）。
   - 正常交锋里，**单人一次开口通常 1–2 句说完**；若必须交代一段复杂事实或揭穿整个阴谋，拆成“抛出一半证据 → 对手急着打断反驳 → 主角顺势甩出后半截杀招”的多轮交互。
3. **转场硬切，不写过场水戏**
   - 离开会议室、坐车去下一地点、回家换衣服再吃饭这类无冲突过场，一律砍掉；用空行或一句短交代直接硬切进下一场正在发生的矛盾现场。
4. **与传统出版小说的 3 处刻意区分（避免惯性回漂）**
   - **少写无关“手头事务”和细腻环境光影**：除非器物或天气直接服务于当下博弈、伏笔或反差，否则不花笔墨铺陈氛围。
   - **爽点与反差直接打透**：情绪到顶或真相揭穿时，不强求“半句留白”和过度克制；把关键人物的错愕、失算、反转后的利益落差实打实落到纸面上（但具体怎么写由本篇声口决定，不套固定路人惊呼公式）。
   - **砍掉高潮后的“消化续场”**：短篇里，一场大爽之后立刻落新局面或抛下一个钩子，不在原地写大段复盘与心理消化。
5. **平台引号适配（含知乎盐言 `「」` 规范）**
   - 番茄 / 七猫 / 点众 / 黑岩等默认使用简体中文全角双引号 `“”`（嵌套用 `‘’`）。
   - 若目标平台为**知乎盐言**（或用户主动要求），全篇对话统一使用直角引号 `「」`（引号内嵌套用 `『』`），且**严禁 `“”` 与 `「」` 混用**；`lint_webnovel.py` 已原生兼容两种引号统计。

## 3. 单篇「原声定调切片」（防千文一面的核心锚点）

同一套规则连写十篇短篇，最容易写成一个味。解决方法不是增加规则，而是**每篇独立锚定声口**：

1. **开篇试写（300–500 字）**：正式推全篇前，直接拿第 1 节/第 1 章开头试写一段，验证两件事：
   - 手机竖屏扫一眼，顺不顺滑、抓不抓人？
   - 语调贴不贴这个具体脑洞？（冷峻复仇、荒诞发疯、市井机灵、诡异怪谈应当一眼区分。）
2. **固化原声切片**：用户觉得对味后，把最传神的 **200–300 字原文** 直接粘贴进 `00_脑洞与节拍.md` 的「定调原声切片」栏；后续每次续写前只读这一小段调音。
3. **禁止跨篇套用桥段模板**：本技能**刻意不提供**“标准打脸句式库”或“标准反派反应公式”。写每一轮爽点时，从本篇对手的真实人设和利益痛点出发去写反应，不复读“全场鸦雀无声 / 倒吸一口凉气 / 怎么可能”。

---

## 4. 极简「真·自动驾驶废料」警戒线

只拦截模型高速生成时最常自动漏出的**纯翻译腔与工业陈词**——这些不是创意，删掉永远提升质量；**严禁扩大化去封杀正常口语词和常用动作词**（如“突然、沉默、冷笑、皱眉、盯着、竟然”等完全正常，按需自然使用）：

| 真正需要避开的模型废料 | 简单处理方式 |
|---|---|
| 旁白二元说教：`不是……而是……` / `与其说……不如说……` | 删掉否定前半句，直接写事实或结果 |
| 汇报拔高腔：`这不仅仅是一场……更是……` / `命运的齿轮开始转动` | 直接删掉，用实实在在的赌注或局面变化说话 |
| 翻译腔虚修饰：`一种难以言喻的……` / `名为XX的种子/火焰` | 直接写具体感受、念头或动作 |
| 泛滥工业神态：`嘴角勾起一抹弧度` / `眼底闪过一丝精光` / `瞳孔地震` / `空气仿佛凝固` | 换成符合当前角色身份与处境的真实反应 |
| 解释性尾巴：`仿佛在证明……` / `这无疑意味着……` / `显然已经说明……` | 事实写明白就行，不替读者画蛇添足做阅读理解 |
| **叠加式描写（同一动作硬掰三段）**：把同一个瞬间按“发生 → 感知 → 身体反应”拆成三段反复说一遍（如先写拿笔，另起一段写手抖，再另起一段写字写歪） | 揉进同一段连续画面里一次写透，既干脆利落又避免“假短段注水” |

> **口语与标点豁免**：角色对白或第一人称鲜活吐槽中出现的自然对比（如“我不是要你道歉，我是要你赔钱”）、正常破折号/省略号语气停顿、生活化鲜活比喻和口头禅，**一律放行**，绝不机械阉割人味。
