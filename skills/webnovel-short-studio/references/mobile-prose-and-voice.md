# 手机端网感、番茄核心技法与单篇声口定调

在 `voice`（开篇试写定调）与 `draft`（正式撰写/续写）阶段读取。

> **核心纪律**：本指南负责**媒介校准与可落地技法**（既防滑回传统出版长段说教腔，也防写僵成 AI 模板碎段），绝不为所有作品套用同一口吻或刻板的单段硬字数红线。

---

## 1. 先选本篇「推进叙事类型」（告别一刀切）

先在 `00_脑洞与节拍.md` 中选定主形态，正文与 `lint_webnovel.py` 据此自适应校准：

| 推进类型 (`--narrative`) | 适用题材 | 核心推进引擎 | 对话与叙述体感 |
|---|---|---|---|
| **`dialogue`（强对话交锋型）** | 微短剧爽文、都市/古言职场家庭赌局、群像打脸 | **短促台词交锋 + 动作神态锚点** | 对话占主体，信息拆进质问、顶嘴、甩底牌与补刀里，但严禁纯裸对话连排堆砌。 |
| **`first_person`（第一人称强叙述吐槽型）** | 知乎盐言、番茄第一人称复仇/发疯/重生/高概念自述 | **极强主观口吻 + 犀利短评 + 密集翻转** | 不硬凑水对话；靠主角贴脸讲故事的狠劲、荒诞感、冷幽默吐槽与关键一锤定音台词拉爽感。 |
| **`rules`（规则/悬疑信息流型）** | 规则怪谈、系统漏洞推演、无限流脑洞、高智商反转 | **冷峻观察 + 反常细节 + 规则条目与短句破绽** | 允许穿插规则清单或冷静推演段，用“规则/冷静长段 + 一句发凉的短句破绽”打出强反差。 |

---

## 2. 手机竖屏媒介校准与排版底线

手机一屏仅容 15–18 行（每行约 16–20 字），抓牢以下高维体感与番茄投稿前排版底线即可：

1. **以 1–3 行短段为基调，主动保护长短反差**：一段写清一个动作或一层意思即换段；爆点狠话、反转揭晓自然单句成段；毒舌连珠炮、蓄势或规则揭秘可放开写 90–140 字完整强段再以短句收口。**严禁**机械切碎成满屏 20–30 字的均匀“电报排骨”，更**严禁**连续 4 段以上 3–10 字的**阶梯式假排版**。
2. **拆碎百字演讲台词**：正常交锋单人一次开口 1–2 句说完；交代复杂事实或揭穿阴谋，拆成“抛出一半证据 → 对手急着打断反驳 → 主角顺势甩出后半截杀招”的多轮交互。
3. **转场硬切，不写过场水戏**：无冲突的坐车、换衣、赶路一律砍掉，空行或 `* * *` 硬切进下一场正在发生的矛盾现场。
4. **引号与标点排版卫生**：
   - 番茄/七猫/点众/黑岩用全角双引号 `“”`（嵌套 `‘’`）；**知乎盐言**全篇统一用直角引号 `「」`（嵌套 `『』`），严禁混用。
   - 杜绝中文句内混入英文标点（`, . ? ! : ;`）、句中误插空格、非常规装饰符号（`△★♥♛√`）、破折号泛滥（整章密布 `——`）以及句中误敲回车留下的逗号断行。

## 3. 番茄官方核心写活技法（短篇落地精要）

1. **场景拆散进动作对话（不暂停剧情写说明书）**
   - 五感以视觉搭架、他感（温度/气味/声响/触感）给质感；用**题材专属具体物件**代替形容词结论，把环境细节切碎融进角色正在做的动作与对话里，绝不在开打或对峙前停下来写一段静态风景说明书。
2. **动作描写：二次动作法与情绪停顿节点（划清与“叠加注水”的边界）**
   - **二次动作替代内心独白**：别写“她心里不舍又犹豫”，改写第一反应后的停顿、收回或按住（如把钥匙推到桌边，指尖却在挂件上多停了一秒才松手）。
   - **情绪转折留 1–2 个停顿节点**，并按角色**年龄、身份与体态**区分动作惯性（老人稳慢、少年急冲、体面人克制微颤）。
   - **边界清晰**：**普通日常动作一次写透**（禁把“拿笔 → 手抖 → 字歪”硬拆三段假短段注水）；**只有关键戏眼与情感转折**，才把动作拆成 3–5 步配合二次动作与停顿放慢放大。
3. **细节去留「三问筛选法」**
   - 写完或删改细节时问三句：① 能否引发读者情感偏向？② 能否让角色更立体？③ 能否为后文反转铺垫？**中一即留，全无即删**。
4. **单章多维手法穿插**
   - 哪怕 `dialogue` 模式，单章也应交叉运用**动作、对话、环境、心理、旁观者气氛反应**至少 2–3 种，严防整章写成干念剧本或连打三章纯动作戏。
5. **防短对话堆砌（对齐番茄 2026-11 红线）**
   - 面对面快节奏交锋**最多连 2–3 句纯引号裸接**，随后必须穿插动作、神态、停顿或环境锚点；顺手合并 `嗯/啊/是吗/然后呢` 等纯过渡水词。
   - **明确豁免**：短信、微信群聊、电话免提、直播弹幕、论坛留言、围观群众七嘴八舌议论可自然连排。
6. **双向节奏把控（既防拖沓，也防过快断档）**
   - 删掉 `接着/然后/后来/最后` 流水账过渡词；同时严防“反派刚挑衅主角一抬手秒杀”导致节奏过快见底——关键交锋须走出「**受阻 → 尝试 → 再受阻 → 转折**」小拉锯，并在拉锯中持续抛出新信息。
7. **章节边界三节点 & 新人出场三要素标签**
   - 每章结尾必须落在「**小事件收束 / 悬念立住 / 人物关系变化**」至少其一，严禁按字数硬截断或在对话/打斗中途乱分章；章首禁千篇一律天气/晨起模板，章尾禁上帝视角空泛哲理升华。
   - 开篇控制同屏出场人数（防人名轰炸）；**每名新人物首次亮相，迅速交代三要素**：是谁、跟谁有关、此刻为何重要。
8. **描写做减法**
   - 名词少叠空洞修饰词，单章比喻宁缺毋滥、不重复喻体；删去反直觉过度精确数值（如“嘴角勾起两毫米的微笑”）和无画面的抽象通感；非系统面板/任务弹窗时，绝不整段罗列工整的 `键：值` 参数图纸清单。

## 4. 单篇「原声定调切片」（防千文一面的调音叉）

1. **开篇试写（300–500 字）**：正式推全篇前，拿开头试写验证三件事——竖屏滑读顺不顺、语调贴不贴本篇脑洞、有没有活人温度与钩子张力。
2. **固化原声切片**：把最对味的 **200–300 字原文**写入 `00_脑洞与节拍.md`，后续每章动笔前只读此段调音；严禁跨篇套用固定“全场鸦雀无声/倒吸凉气”打脸模板。
3. **Gate 1 试写停顿**：默认直接连贯写完全文；仅当用户明确要求“先试写”时，写完前 2 章并附 B 轨自评后暂停交由用户拍板文风。

## 5. 极简「真·自动驾驶废料」警戒线

只拦模型高速生成时漏出的翻译腔与工业套话，**不封杀正常常用词**（“突然、沉默、冷笑、皱眉、盯着、竟然”均可自然使用，只要别用空洞单句 `"他冷笑一声"` 走过场）：

| 需要避开的模型废料 | 处理方式 |
|---|---|
| 旁白工整关联句：`不是……而是……` / 反复 `不是……是……` / `是……是……` / `与其说……不如说……` | 删去否定前半句直接写事实，打破成对工整模板（第一人称偶发自然口语对比除外） |
| 汇报拔高与翻译腔：`这不仅仅是一场……更是……` / `命运的齿轮` / `一种难以言喻的……` / `名为XX的种子` | 直接删掉，换具体赌注、感受或动作 |
| 工业神态与疼痛废料：`嘴角勾起弧度` / `眼底闪过一丝精光` / `瞳孔地震` / `空气凝固` / `指节/骨节发白` / `指甲嵌进掌心` | 改用二次动作、温度差微感官或贴合当下处境的真实反应 |
| 解释性尾巴与同构排比：`仿佛在证明……` / `这无疑意味着……` / 连续 3 句以上同起句短句排比 | 事实写透即止，错开句式长短起伏 |
| 病句长难句与代词混乱：`望着……让……` 缺主语超长句 / 同段多人交锋连用四五个“他” | 及时断句补主语；多人同场直呼姓名或身份标签 |
| 公文/办件说明书腔（详见 [emotion-and-tension.md](emotion-and-tension.md)） | 口语简称文件、压手续，笔墨还给当面交锋 |
