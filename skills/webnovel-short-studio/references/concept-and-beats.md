# 脑洞压测、一页规则卡与双模板爽感节拍

在 `hook`（脑洞孵化与立项）或 `beat`（节拍规划与快检）阶段读取。

---

## 1. 上游扫文雷达与拆文产物对接（防洗稿转化协议）

本技能可直接承接独立扫文雷达 **`webnovel-market-radar`** 或外部拆文工具的落盘文件，按来源提取合法骨架并强制原创化：

| 上游文件来源 | 允许提取的抽象信号 | 严格隔离项 |
|---|---|---|
| `选题简报.md`（`webnovel-market-radar`）或 `选题决策.md` | 目标平台、建议体量模板（`flash`/`microdrama`）、推荐推进形态、情绪痛点、差异化缺口、失败风险与验证动作 | 仅作市场锚点，不照搬参考书具体剧情 |
| `扫榜报告.md`（短/长篇扫榜报告） | 情绪热度趋势、热门字数区间、开头/结尾偏好、标题与导语规律 | 单本上榜只算个例，不复刻对标书名与人设 |
| `拆文库/{书名}/`（`拆文报告.md` / `_meta.json` / `写作手法.md`） | `genre_detected`、反转类型（视角/身份/信息/认知）、情感拉扯层级、共鸣维度与大致节奏占比 | **默认屏蔽 `原文/` 不直喂正文写作**；不把节点表当填空题照抄桥段顺序 |

**强制三步转化**：
1. **抽骨架**：提炼目标读者最买单的情绪缺口与期待方向；
2. **换脑洞**：把核心奇观规则、职业/时代切口、人物关系与反转角度**全部重写**（至少置换两项底层核心要素）；
3. **定体量与平台**：锁定 `flash` 或 `microdrama` 模板、推进形态（`dialogue / first_person / rules`）及目标平台排版习惯（如知乎盐言启用 `「」`）。

## 2. 脑洞 4 问压测（立不住就先升级，别带着弱点子硬写）

动笔排大纲前，先用 4 个问题检验核心创意：

1. **3 秒画面感**：能否用 **30 字以内的一句话**，让陌生读者立刻看懂处境并冒出“这怎么破 / 这下好看了”的画面？
2. **持续冲突制造机**：这个脑洞规则能不能自然生出 **3–5 轮递增局面**？（警惕“第一章亮完奇观后面变成普通流水账”的一次性点子。）
3. **反常识错位点**：面对同一个母题，AI 和通俗套路通常会怎么写？本篇往哪儿**拧半圈**才能让人眼前一亮？
4. **智商与爽感平衡点**：主角破局靠的是**信息差、规则漏洞、隐藏硬底牌或对手的真实贪欲盲区**，还是只能靠反派突然变傻？
   - **底线**：允许反派自负、势利、贪心或掌握信息不全（这很真实，也能痛快打脸），但尽量不写“当众自爆罪证、明知会死还送人头”的弱智工具人。

若以上任一问发虚，直接给出 **2–3 个高概念升级变体** 供用户挑一个拍板，再往下走。

## 3. 一页纸高概念规则卡（替代重型世界观）

5 万字以内短篇不需要地理、税制、编年史，所有设定压缩在 `00_脑洞与节拍.md` 的一页之内，只写直接驱动冲突的东西：

- **一句话高概念**：谁 + 绑定/遭遇了什么反常识规则或极端处境 + 立刻面临什么危机或博弈。
- **唯一核心规则（金手指 / 奇观机制）**：怎么触发、能带来什么不对等优势（1–2 句说死，读者一眼懂）。
- **规则边界 / 漏洞 / 限制**：为什么主角不能第 1 页就无敌通关？恰恰是边界和漏洞制造反转与高智商破局。
- **核心人物（精简到 2–5 人）**：
  - **主角**：明面弱势/伪装身份 + 隐藏硬底牌/反杀性格（不内耗、行动力强）。
  - **1–2 名核心对手**：他们的**真实利益诉求与致命盲区**（因为贪什么、以为主角缺什么，才会一步步踩进局里）。
  - **1–2 名功能配角**：盟友、关键见证人、利益第三方或关系反差载体（没冲突功能的人坚决不加）。

## 4. 爽感维度工具箱（用来做「爽感叠加」，不是写死演法）

编辑痛点之一是“同一种打脸写三遍就疲了”。规划节拍时，要求**相邻的大爽点至少切换或叠加 1 种新维度**：

| 爽感维度 | 底层快感来源 | 典型高智商切口 |
|---|---|---|
| **1. 信息差 / 预知爽** | 主角知道对手不知道的真相、未来、弹幕或心声 | 对手以为自己在局外算计，实则每步都在主角预判里 |
| **2. 规则漏洞 / 反噬爽** | 利用系统条文、合同细则、怪谈守则或对方定下的规矩反杀 | 用对方亲手画的圈套，按对方认的规则把对方套死 |
| **3. 身份 / 实力掉马爽** | 被低估的真实筹码、专业壁垒或隐藏身份在关键时刻亮明 | 前期克制蓄压，亮牌瞬间彻底改写全场权力位次 |
| **4. 利益倒置 / 借刀爽** | 顺着对手的贪念推一把，让对手亲手毁掉自己的退路或内部反目 | 不必主角亲自苦战，对手抢着抢走一个包装好的炸弹 |
| **5. 情绪宣泄 / 掀桌爽** | 拒绝道德绑架、不圣母不原谅，用极干脆的行动切断烂局 | 对方以为拿捏了亲情/体面/软肋，主角反手连桌子一起掀了 |
| **6. 认知翻转 / 伏笔回收爽** | 前文一个被所有人嘲笑的蠢举动或小细节，瞬间反转成神来之笔 | 让读者拍大腿：“原来开头那句铺垫是为了这一下！” |

> **注意**：上表用于规划**剧情结构里的爽感组合**，绝不规定正文里必须用“路人倒吸凉气/反派脸色铁青”来演。具体怎么呈现，由本篇题材和声口决定。

## 5. 内置双节奏模板

### 模板 A：`flash` 超短篇（约 0.8–3 万字 · 知乎盐选 / 番茄短故事 / 强反转爆文）

适合单核心脑洞高度闭环、一口气读完的极致密度体验。可按 1 篇连贯长文分小节，或拆为 **4–12 章（每章 1500–2500 字）**。

| 进度占比 | 阶段定位 | 必须完成的任务 |
|---|---|---|
| **0%–5%（前 300–500 字）** | **黄金入局** | 零前情提要！直接砸出反常识规则、正在发生的羞辱/危机，或一句极具冲击力的现状反差。 |
| **5%–15%（前 1500 字内）** | **首次验证 / 小钩子** | 让读者亲眼看见脑洞规则生效，给出第一次可感知的小破局、小反击或强烈悬念，兑现点击承诺。 |
| **15%–45%** | **第 1–2 轮递进爽点** | 对手按常规认知加码试探或打压；主角利用**维度 A**反杀，同时拿到第一份实质筹码，引出更深一层利益或秘密。 |
| **45%–70%** | **假危机 + 换维度中反转** | 对手发现不对劲，亮出杀手锏或搬出更硬的靠山，局势看似逆转；主角切入**维度 B（如规则漏洞或伏笔回收）**反将一军，叠加第二重爽感。 |
| **70%–92%** | **终局大掀桌** | 全场筹码摊牌，回收开头埋下的最核心明牌伏笔，让对手在最自信的时刻彻底翻车，完成最高强度的情绪释放。 |
| **92%–100%** | **短促落点 / 回马枪** | 迅速收尾（300–800 字内），落在一个干脆利落的新局面、绝妙冷幽默或细思极恐的回马枪上，绝不拖泥带水写大团圆总结。 |

### 模板 B：`microdrama` 微短剧式短中篇（约 2–5 万字 · 10–25 章 · 强连载卡点）

适合人设鲜明、冲突频繁、每章像一集微短剧一样钩着往下点。单章建议 **1600–2400 字**。

- **黄金开篇（第 1–2 章，约 3200–4500 字）**：
  - 第 1 章前 500 字入局立奇观，章末必须卡在「危机爆发 / 底牌初露 / 当场对峙」的硬悬念上；
  - 第 2 章内完成第一次痛快小兑现，同时拉出贯通全篇的更大赌局或主线目标。
- **中段爽感循环（每 3–5 章为一个小单元）**：
  - 每个单元遵循：`新压迫/新赌局 → 主角表面顺势或暗中布局 → 对手自信踩坑 → 反杀揭晓并收割新筹码 → 触发更高级别冲突`；
  - **强制切换爽感维度**：单元 1 若主打信息差打脸，单元 2 切入规则反噬或身份错位，单元 3 切入借刀反噬或情感掀桌，保持新鲜感；
  - **单章铁律**：每章至少 1 个清晰的情绪落差（压→扬 或 悬→破）+ 1 个**章末硬钩子**，严禁安排纯赶路、纯开会、纯疗伤复盘的过渡水章。
- **高潮与终局（最后 2–3 章）**：
  - 汇合前序所有明牌线索与积累的筹码，完成终极格局反转与彻底清算，最后留 1 场利落余韵收官。

## 6. 节拍表 4 项快检（替代复杂量化大表）

排完节拍表后，动笔前花 30 秒核对这四条：

1. **前 500 字有没有直接入戏？**（有没有犯“先介绍主人公身世和背景两百字”的老毛病？）
2. **有没有连续超过 1500 字没有新冲突、新信息或情绪释放的水段？**（有就合并或硬切。）
3. **相邻两轮爽点有没有换花样？**（如果全是同款“反派嘲讽→主角甩钱/甩证”，立刻重写其中一轮的博弈机制。）
4. **核心反转的明牌线索提前埋了吗？**（确保读者翻到反转时是“原来前面那个细节在这儿等着！”，而不是作者临时掏出一个没提过的金手指。）

## 7. 爆款标题 + 平台导语/简介（可选商业转化产出）

短篇的点击率与完读起点很大程度上由**标题 + 导语/简介**决定。在 `hook` 定向或 `export` 交稿时，可按用户需要顺手输出 **3 个备选标题 + 1 版适配目标平台的导语/简介**（存入 `00_脑洞与节拍.md`，不混入纯净正文文件）：

### 标题备选思路（给 3 个不同切口供挑选）
- **事件反杀型（番茄/七猫/点众/黑岩高频）**：`[极端处境/脑洞异常] + [被轻视或逼迫] + [反手掀桌结果]`，直给画面、忌文艺谜语。
- **反差脑洞型（高概念爆文）**：突出规则漏洞或身份错位的“反常识一句话”。
- **精短钩子型（知乎盐言偏好，常 6–14 字）**：一句话事件、极端反差或自带提问感。

### 各平台导语/简介结构速查

| 目标平台 | 建议字数 | 导语核心结构 | 关键注意点 |
|---|---|---|---|
| **知乎盐言** | 200–500 字 | 人物关系 + 核心异常/冲突 + 2–3 处小转折 + 金句或强悬念收口 | **简介即独立微小说**，直接决定付费/点击转化；不写设定说明书 |
| **番茄短故事 / 短中篇** | 120–260 字 | 一句话奇观/处境 → 最戳心的压迫或一句狠话 → 底牌/反杀预告 + 悬念钩子 | 第一句直接进冲突，禁止“这是一个关于……”的文艺开场 |
| **七猫 / 点众 / 黑岩** | 120–300 字 | 正常表象被打破 → 最伤人的一句对白或事件 → “这一次我……”态度翻转 → 结局悬念 | 可含 1 句高张力台词，把最炸的冲突前置到前 80 字 |
| **通用 / 投编辑审阅** | 150–250 字 | 一句话高概念 + 爽点升级路径预览 + 核心反转悬念（不剧透终极底牌） | 写得像电影预告片，不写流水账梗概 |
