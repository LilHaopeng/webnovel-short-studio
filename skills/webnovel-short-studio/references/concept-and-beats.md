# 脑洞压测、一页规则卡与双模板爽感节拍

在 `hook`（脑洞孵化与立项）或 `beat`（节拍规划与快检）阶段读取。

---

## 1. 上游扫榜雷达与拆文产物对接（防洗稿转化协议）

本技能可直接承接 `webnovel-market-radar` 或外部拆文工具的落盘文件，提取抽象骨架并强制原创化：

| 上游文件来源 | 允许提取的抽象信号 | 严格隔离项 |
|---|---|---|
| `选题简报.md`（`webnovel-market-radar`） | 目标平台、建议体量模板（`flash`/`microdrama`）、推荐推进形态、情绪痛点、差异化缺口与风险点 | 仅作市场锚点，不照搬参考书具体剧情 |
| `扫榜报告.md`（短/长篇扫榜报告） | 情绪热度趋势、热门字数区间、开头/结尾偏好、标题与导语规律 | 单本上榜只算个例，不复刻对标书名与人设 |
| `拆文库/{书名}/`（`拆文报告.md` / `_meta.json` / `写作手法.md`） | 题材类型、反转类型（视角/身份/信息/认知）、情感拉扯层级与大致节奏占比 | **严格屏蔽 `原文/` 不直喂正文写作**；不把节点表当填空题照抄桥段顺序 |

**强制三步转化**：① 抽骨架（提炼目标读者买单的情绪缺口） → ② 换脑洞（核心规则、职业/时代切口、人物关系与反转路径至少置换两项底层要素） → ③ 定体量与平台（锁定 `flash`/`microdrama`、推进类型及引号规范，如知乎盐言用 `「」`）。

## 2. 脑洞 5 问压测（立不住就先升级，别带着弱点子硬写）

动笔排节拍前，先用 5 问检验核心创意；任一问发虚，直接给出 2–3 个高概念升级变体再推进：

1. **3 秒画面感**：能否用 **30 字以内的一句话**，让陌生读者瞬间看懂处境并冒出“这怎么破 / 这下好看了”的画面？
2. **持续冲突制造机**：核心规则或关系死结能否自然生出 **3–5 轮递增局面**？（警惕第一章亮完奇观后面沦为流水账的一次性点子。）
3. **反常识错位点**：面对同一母题，通俗套路和 AI 通常会怎么写？本篇往哪儿**拧半圈**才能让人眼前一亮？
4. **智商与爽感平衡点**：主角破局靠的是**信息差、规则漏洞、隐藏底牌或对手的真实人欲盲区**，还是只能靠反派突然降智自爆？（反派设计原则详见 [emotion-and-tension.md](emotion-and-tension.md)。）
5. **情绪刺点 / 追读拉力**：强情绪与关系博弈题材看前 1,000 字能否让读者感到真实刺痛与人物拉扯；规则怪谈/脑洞喜剧题材看能否在开局立住紧迫生存悬念或荒诞张力。

## 3. 一页纸高概念规则与关系卡（替代重型世界观）

5 万字以内短篇不需要地理、税制与编年史，所有设定压缩在 `00_脑洞与节拍.md` 一页之内，只留直接驱动冲突的要素：

- **一句话高概念**：谁 + 遭遇/绑定了什么反常识规则或极端处境 + 立刻面临什么危机或博弈。
- **唯一核心规则 / 核心关系死结**：怎么触发、带来何种不对等优势（1–2 句说死，读者一眼懂；纯情感短篇写清关系死结与筹码）。
- **规则边界 / 代价 / 限制**：为什么主角不能第 1 页就无敌通关？恰恰是边界、成本与羁绊制造拉扯和反转张力。
- **核心人物（精简 2–5 人，命名严守 [naming-and-titling.md](naming-and-titling.md)，立体度对齐 [emotion-and-tension.md](emotion-and-tension.md)）**：
  - **主角**：明面处境 + 表里反差切面 + 真实底牌与软肋。
  - **1–2 名核心对手**：道德支点、沉没成本、局部正确性与致命盲区。
  - **1–2 名官配 / 关键盟友**：独立立场与算盘、关系拉扯弧线及关键时刻的不配合节点（绝不空降工具人）。

## 4. 爽感维度工具箱（做「爽感叠加」，不写死演法）

规划节拍时，**相邻的大爽点至少切换或叠加 1 种新维度**，防止同款打脸写三遍发腻：

| 爽感维度 | 底层快感来源 | 典型高智商切口 |
|---|---|---|
| **1. 信息差 / 预知爽** | 主角知道对手不知道的真相、未来、弹幕或心声 | 对手以为在局外算计，实则每步都在主角预判里 |
| **2. 规则漏洞 / 反噬爽** | 利用系统条文、合同细则、怪谈守则或对方定下的规矩反杀 | 用对方亲手画的圈套，按对方认的规则反套回去 |
| **3. 身份 / 实力掉马爽** | 被低估的真实筹码、专业壁垒或隐藏身份在关键时刻亮明 | 前期克制蓄压，亮牌瞬间改写全场权力位次 |
| **4. 利益倒置 / 借刀爽** | 顺着对手的贪念推一把，让对手亲手毁掉退路或内部反目 | 不必主角苦战，对手抢着抱走一个包装好的雷 |
| **5. 情绪宣泄 / 掀桌爽** | 拒绝道德绑架、不圣母不原谅，用极干脆的行动切断烂局 | 对方以为拿捏了软肋，主角反手连桌子一起掀了 |
| **6. 认知翻转 / 伏笔回收爽** | 前文被嘲笑的举动或不起眼旧物，瞬间反转成神来之笔 | 读者拍大腿：“原来开头那笔铺垫在这儿等着！” |

> 上表仅用于规划剧情结构组合，具体演出服从本篇题材与声口，不套用固定“全场倒吸凉气”模板。

## 5. 内置双节奏模板

### 模板 A：`flash` 超短篇（0.8–3 万字 · 知乎盐言 / 番茄短故事 / 强反转爆文）

适合单核心脑洞高密度闭环，可按连贯长文分小节，或拆为 **4–12 章（每章约 1500–2500 字；明确上传七猫时再按需拆分 500–1500 字/章）**：

| 进度占比 | 阶段定位 | 必须完成的任务 |
|---|---|---|
| **0%–5%（前 300–500 字）** | **黄金入局** | 零前情提要，直接砸出反常识规则、正在发生的危机或强烈处境反差。 |
| **5%–15%（前 1500 字内）** | **首次验证 / 小钩子** | 让读者亲眼看见规则生效，给出第一次当场小破局、小反击或硬悬念，兑现点击承诺。 |
| **15%–45%** | **第 1–2 轮递进爽点** | 对手按常规认知加码试探/打压；主角以**维度 A**反杀并拿到第一份实质筹码，引出更深秘密。 |
| **45%–70%** | **假危机 + 换维度中反转** | 对手亮杀手锏或搬硬靠山令局势看似逆转；主角切入**维度 B（规则漏洞/伏笔回收）**反将一军。 |
| **70%–92%** | **终局大掀桌** | 全场筹码摊牌，回收开头埋下的最核心明牌伏笔，完成最高强度的情绪释放。 |
| **92%–100%（300–800 字）** | **短促落点 / 回马枪** | 迅速收尾，落在一个利落的新局面、冷幽默或细思极恐回马枪上，绝不写大团圆总结。 |

### 模板 B：`microdrama` 微短剧式短中篇（2–5 万字 · 10–25 章 · 强连载卡点）

适合人设鲜明、冲突密集、章章带卡点。单章默认 **1600–2400 字**（仅明确上传七猫时按需拆分 `500–1500` 字/章）：

- **黄金开篇（第 1–2 章，约 3200–4500 字）**：第 1 章前 500 字入局立奇观，章末卡在危机爆发/底牌初露/当场对峙；第 2 章内完成首次痛快小兑现并拉出全篇主线赌局。
- **中段爽感循环（每 3–5 章一单元）**：遵循「新压迫 → 顺势布局/拉锯 → 对手踩坑 → 反杀收割筹码 → 触发更高级别冲突」；相邻单元强制切换爽感维度；每章必有清晰情绪落差与章末节点钩子，禁纯赶路/开会/复盘水章。
- **高潮与终局（最后 2–3 章）**：汇合前序全部明牌线索与筹码完成彻底清算，留 1 场利落余韵收官。

## 6. 节拍表 6 项快检

动笔前花 30 秒逐条核对：

1. **前 500 字有没有直接入戏？**（是否犯了先交代两百字背景身世的老毛病？）
2. **有没有“纯筹备 / 纯取证 / 纯等明天”的水章，或相反“冲突一抬手就秒解决”的断档？**（每章当场必有戏眼，关键交锋留出「受阻—尝试—再受阻—转折」拉锯。）
3. **相邻两轮爽点有没有换维度？**（连打同款套路立刻重写其中一轮切口。）
4. **核心反转的明牌线索提前埋了吗？**（保证回收时读者惊呼“原来伏笔在那儿”，而非临时掏金手指。）
5. **反派动机与主角痛感/成本站得住脚吗？**（反派有真实人欲逻辑，主角选择有真实成本。）
6. **盟友 / 官配的关系推进有过程吗？**（有试探、博弈或拒绝配合，而非零铺垫空降兜底。）

## 7. 书名定调指针与平台导语速查

- **书名与章节命名**：完整规则、5 大书名型谱（含商业高点击型 4/型 5 与知乎盐言短名型 1–3）、异构 3 备选机制及 4 套章节命名体制见 [naming-and-titling.md](naming-and-titling.md)。核心纪律：严禁把内部一句话梗概直接充当正式书名，且章节名绝不剧透反转。
- **各平台导语 / 简介结构速查**：

| 目标平台 | 建议字数 | 导语核心结构 | 关键注意点 |
|---|---|---|---|
| **知乎盐言** | 200–500 字 | 人物关系 + 核心异常/冲突 + 2–3 处小转折 + 金句或强悬念收口 | 简介即独立微小说，直接决定点击与付费转化；不写设定说明书 |
| **番茄短故事 / 短中篇** | 120–260 字 | 一句话奇观/处境 → 最戳心的压迫或一句狠话 → 底牌/反杀预告 + 悬念钩子 | 第一句直接进冲突，禁止“这是一个关于……”的文艺开场 |
| **七猫短故事** | 建议 120–300 字（平台上限 ≤500 字） | 正常表象被打破 → 最伤人的一句对白或事件 → 态度翻转 → 结局悬念 | 可含 1 句高张力台词，把最炸的冲突前置到前 80 字 |
| **点众 / 黑岩** | 120–300 字 | 公开羞辱/信任陷阱/倒计时前置 → 隐藏底牌亮刃 → 强烈悬念钩子 | 信息密度高，把核心对立面放在第一段 |
| **通用 / 投编辑审阅** | 150–250 字 | 一句话高概念 + 爽点升级路径预览 + 核心反转悬念（不剧透终极底牌） | 写得像电影预告片，不写流水账梗概 |
